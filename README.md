**Improving semantic segmentation of tear meniscus for dry eye disease diagnosis via modern architectures and advanced training techniques.**

## 📊 Project Overview

This project implements a systematic 3-phase research plan to improve tear meniscus segmentation from baseline **F1=0.9220** (U-Net) to **≥0.93-0.96 F1** using:

- **Phase 1**: Architecture upgrades + enhanced augmentation (Weeks 1-2)
- **Phase 2**: Transformer-based segmentation (Weeks 3-4)  
- **Phase 3**: Self-supervised learning + domain adaptation + ensemble methods (Weeks 5-9)

## 🎯 Baseline Performance

| Model | F1 Score | Recall | Precision | MIoU |
|---|---|---|---|---|
| **U-Net** | 0.9220 | 0.9127 | 0.9367 | 0.9279 |
| ResUNet | 0.9025 | 0.8840 | 0.9286 | 0.9109 |
| DeepLabV3+ | 0.8705 | 0.8533 | 0.8957 | 0.8841 |

*Source: Figshare Pixel-Level Tear Meniscus Segmentation Dataset with Multimodal Imaging*

## 🚀 Quick Start

### 1. Clone and Setup

```bash
git clone https://github.com/Novabricot/tear-meniscus-segmentation.git
cd tear-meniscus-segmentation

# Create virtual environment
python -m venv venv
source venv/bin/activate  # On Windows: venv\Scripts\activate

# Install dependencies
pip install -r requirements.txt
```

### 2. Prepare Dataset

```bash
# Extract dataset archive to data/raw/
# Expected structure:
# data/raw/Open DataSet2/<modality>/Original/
# data/raw/Open DataSet2/<modality>/Label/

# Preprocess and split dataset
python scripts/preprocess_data.py --input data/raw/Open DataSet2 --output data/processed
```

### 3. Train U-Net on the Tear Meniscus Dataset

```bash
# Train the U-Net baseline with segmentation models and progressive augmentations
python scripts/train_unet.py \
    --config configs/unet_config.yaml \
    --epochs 60 \
    --batch-size 8

# Monitor training
tensorboard --logdir results/unet/
```

### 4. Run Phase 1 (Quick Wins)

```bash
# Train DeepLabV3+ ResNet-101
python PHASE_1_QUICKWINS/scripts/train_phase1.py \
    --config PHASE_1_QUICKWINS/configs/phase1_config.yaml \
    --epochs 100 \
    --batch-size 8

# Monitor training
tensorboard --logdir results/phase_1/
```

### 4. Run Phase 2 (Transformers)

```bash
# Train SegFormer-B3
python PHASE_2_TRANSFORMERS/scripts/train_phase2.py \
    --config PHASE_2_TRANSFORMERS/configs/phase2_config.yaml \
    --model segformer-b3 \
    --epochs 100
```

### 5. Run Phase 3 (Advanced)

```bash
# Self-supervised pretraining on all images
python PHASE_3_ADVANCED/scripts/train_simclr_pretrain.py \
    --config PHASE_3_ADVANCED/configs/phase3_config.yaml

# Domain adversarial training
python PHASE_3_ADVANCED/scripts/train_domain_adversarial.py \
    --config PHASE_3_ADVANCED/configs/phase3_config.yaml

# Ensemble training
python PHASE_3_ADVANCED/scripts/train_ensemble.py \
    --config PHASE_3_ADVANCED/configs/phase3_config.yaml
```

## 📊 Evaluation & Comparison

```bash
# Evaluate all models
python scripts/eval.py \
```

## 🏗️ Project Phases

### **PHASE 1: Quick Wins** (Weeks 1-2)
✅ **Target**: F1 = 0.90-0.91 (+2-3% improvement)

- DeepLabV3+ ResNet-101 (upgrade from ResNet-50)
- Enhanced augmentation pipeline (MixUp, ElasticTransform, etc.)
- Progressive augmentation scheduling
- **Effort**: Low | **Impact**: Medium | **Implementation time**: 1-2 weeks

**Key files**:
- [PHASE_1_QUICKWINS/configs/phase1_config.yaml](PHASE_1_QUICKWINS/configs/phase1_config.yaml)
- [PHASE_1_QUICKWINS/scripts/train_phase1.py](PHASE_1_QUICKWINS/scripts/train_phase1.py)
- [docs/PHASE_GUIDES/phase_1_guide.md](docs/PHASE_GUIDES/phase_1_guide.md)

---

### **PHASE 2: Modern Architectures** (Weeks 3-4)
🎯 **Target**: F1 = 0.93-0.94 (+2-4% cumulative)

Options (ranked by practicality):
1. **SegFormer-B3** ⭐ (RECOMMENDED)
   - Efficient transformer backbone
   - 80-100 FPS inference
   - Best balance of accuracy vs. speed
   
2. SegFormer-B5
   - Higher accuracy (~0.94 F1)
   - Slower inference (40 FPS)
   
3. UNetFormer
   - Hybrid CNN-Transformer
   - Lighter than pure transformers
   
4. Mask2Former
   - State-of-the-art (2023)
   - Slower, requires more GPU memory

**Key files**:
- [PHASE_2_TRANSFORMERS/configs/phase2_config.yaml](PHASE_2_TRANSFORMERS/configs/phase2_config.yaml)
- [PHASE_2_TRANSFORMERS/scripts/train_phase2.py](PHASE_2_TRANSFORMERS/scripts/train_phase2.py)
- [docs/PHASE_GUIDES/phase_2_guide.md](docs/PHASE_GUIDES/phase_2_guide.md)

---

### **PHASE 3: Advanced Learning** (Weeks 5-9)
🚀 **Target**: F1 = 0.94-0.96 (+2-4% cumulative)

#### 3A. Self-Supervised Pretraining
- SimCLR on unlabeled IR images (1,739 additional images)
- Transfer learned encoder to SegFormer
- Expected gain: +2-4% F1

#### 3B. Domain Adversarial Training
- Make model robust to Placido ring variations
- Prepare for future headset deployment
- Expected gain: +0.5-1.5% F1 (robustness)

#### 3C. Ensemble Methods
- Train 4-5 SegFormer models with different seeds
- Average predictions for robustness
- Expected gain: +0.5-1% F1

**Key files**:
- [PHASE_3_ADVANCED/scripts/train_simclr_pretrain.py](PHASE_3_ADVANCED/scripts/train_simclr_pretrain.py)
